# Elementor Form Lead Tracker

Gates protected content behind Elementor Pro forms using secure cookie-based tokens. Tracks leads, monitors downloads, and syncs data with GA4 and Freshsales CRM.

## Features

- Content gating behind Elementor form submissions
- Secure cookie-based access tokens (7-day expiry)
- GA4 event tracking integration
- Freshsales CRM lead sync
- Admin dashboard for submission management
- Download tracking

## Usage

1. Upload the `elementor-form-lead-tracker/` folder to `/wp-content/plugins/` and activate.
2. Edit any Elementor Pro form — a new **Lead Tracker** section will appear in the form settings.
3. Configure the protected content URL, GA4 event name, and CRM options.

## Requirements

- WordPress 5.8+
- PHP 7.4+
- Elementor Pro
