# Elementor Pro Plugins

Custom WordPress plugins built to extend Elementor Pro — forms, dynamic tags, lead tracking, and more.

Each plugin lives in its own subfolder with a dedicated README.

## Plugins

| Folder | Description |
|--------|-------------|
| [elementor-form-lead-tracker](./elementor-form-lead-tracker/) | Gate content behind Elementor forms with GA4 + Freshsales CRM tracking |

## Requirements

- WordPress 5.0+
- Elementor Pro
